# WATER-RILAB

WATER-RILAB is a Streamlit-based dashboard for exploring and visualizing environmental and agricultural data.

The application combines WeatherLink station data with spatial and temporal environmental datasets, including daily evapotranspiration (ET) and soil moisture (SM) raster data from DHI.

## Requirements & Installation
The following instructions are intended for Windows. 

The application was developed and tested using:
- Python 3.12.11
- [uv](https://docs.astral.sh/uv/) (version: 0.10.2) for Python environment and dependency management


These are the steps to create and activate the dashboard
```powershell
# Step 1: Create and activate the virtual environment  
uv venv --python 3.12.11
.venv\Scripts\Activate.ps1

# Step 2: Install the dependecies
uv pip install -r requirements.txt

# Step 3: Run the Streamlit application (while the created environment is active)
streamlit run main.py

# Step 4: Accessing the dashboard
http://127.0.0.1:8501

```

## Dashboard Pages & files

### Streamlit pages:
- `main.py` is the main entry point of the dashboard. It displays data collected from the sensors and retrieved from the database, and provides a soil water deficit assessment under the **Soil moisture** tab.
- `map.py` displays the GeoTIFF data on an interactive map and calculates soil water deficit using both ground sensor measurements and DHI-provided data.
- `all_metrics.py` provides an overview of the latest available measurements for all metrics stored in the database.

### Utility files:
- `environment_cache.py` is used to generate the environmental data cache. Since the cache is already precomputed and included in the repository, this file does not normally need to be executed.
- `config.py` contains general application paths and settings used throughout the dashboard. These settings should not normally require modification.
- `config.toml` contains Streamlit-specific configuration, including server and interface settings.




## Database, GeoTIFFs & Cache

### WeatherLink database

The main WeatherLink database and its corresponding schema are located at:

```text
DB/WeatherLink_DB_Main_2026_10_13.db
DB/WeatherLink_DB_Main_schema.sql
```
>**Note**: The schema file is provided for reference and to help understand the database structure. It is not intended to be executed.

### DHI data
For the `map.py` page the application also utilzes soil moisture and evapotranspiration GeoTIFFs from DHI generated by the TSEB model. The date of the GeoTIFFs are in the file name in `yyyymmdd` format.

The data of which can be found here:
```text
DB/DHI_data/
DB/DHI_WeatherLink_DB_Main_schema.sql

DB/DHI_data/DHI_data/Ins4EnvSolutions/
 ├── ET/    -> Daily evapotranspiration GeoTIFFs
 └── SM/    -> Daily soil moisture GeoTIFFs

```

### Environment Cache
The application uses a precomputed environmental data cache for faster GeoTIFF fetching, there is no need to execute or change the `environment_precompute.py` as the data has already been precomputed

Located at:
```text
DB/environment_map_cache.db
```
